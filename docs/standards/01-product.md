# 产品设计规范

维护人：孙翌程。适用于学生端、教师端、机构管理及导出文件的用户体验。

| 编号 | 要求 | 检查方法 |
| --- | --- | --- |
| PROD-01 | 页面必须属于产品页面清单并标明角色、入口和主操作；同一操作只维护一个主入口 | 逐页与清单反向核对；发现孤立页面或未定义角色则退回 |
| PROD-02 | 每个数据视图有加载、正常、空数据、错误四态；任务视图另有排队、失败及重试状态 | 构造空数据、断网、超时和任务失败，检查是否仍有明确操作 |
| PROD-03 | 文案沿用术语表；错误提示说明发生了什么及可执行下一步，不展示堆栈 | 检索近义词混用；逐条核对错误文案与 API 错误码 |
| PROD-04 | 字段在失焦及提交时校验，错误紧邻字段且可被辅助技术读取；保留已填非敏感数据 | 缺必填、错误格式、服务失败后检查错误位置与输入保留 |
| PROD-05 | 提交期间禁用重复触发并展示处理状态；后端幂等是最终约束 | 连点提交、刷新及网络重试，核验最终只产生一次业务效果 |
| PROD-06 | 间距采用 4/8/12/16/24/32 像素，正文 16、辅助 14、标题 20/24/32 像素；业务页复用基础组件 | 新页面与组件清单比对；确需例外登记理由 |
| PROD-07 | 在 360、768、1280 像素宽度检查主路径；键盘可完成表单，焦点可见、标签关联，普通文字对比度目标至少 4.5:1 | 实测三个宽度并键盘走查；题图可局部缩放，整页不得横向溢出 |
| PROD-08 | 图片仅 JPG/PNG，单文件不超过 10 MiB、一次最多 5 张、合计不超过 30 MiB、单图不超过 2000 万像素 | 对上限、上限加一、伪扩展名和损坏图测试；后端同样检查 |
| PROD-09 | 上传后展示完整原图和识别结果；题干、作答、模型建议分区，不把未核验建议标成确定结论 | 使用漏字、缺小问、无作答样例，核验提示和确认入口 |
| PROD-10 | 状态转换遵守统一状态机；多人编辑以版本冲突提示结束，不能静默覆盖 | 双会话修改同一草稿；已发布单换题应创建新版本而非原地改 |
| PROD-11 | PDF 题号、题图、选项与练习快照一致，解析单独导出；反馈入口能定位原练习单 | 按固定题单逐题比对 PDF 与页面，小问不得串号 |
| PROD-12 | 结构化题库导入上限 5 MiB/1000 行，先校验预览，再凭同一文件摘要确认，整批成功才生效 | 混入一行错误则无正式题目新增，错误指出行号；上传图片流程不套用行导入规则 |

## 四状态文案基线

| 状态 | 基本文案与动作 |
| --- | --- |
| 加载 | “正在加载练习……”；允许离开页面，不能显示空状态 |
| 空数据 | “暂无练习。老师发布后会显示在这里。”；教师页提供创建入口 |
| 错误 | “练习加载失败，请重试。若仍失败，可提供请求编号联系支持。”；保留请求编号复制动作 |
| 正常 | 展示实际记录及操作；不能用演示数据替换失败结果 |
| 任务排队 | “已收到材料，正在排队处理。”；提供任务详情 |
| 分析缺依据 | “还缺少你的作答，暂不能判断具体错因。”；提供补充入口 |

上述数值为 v0.1 产品基线。调整须同步规范、接口校验与边界测试；不能只修改前端限制。颜色不得作为正确/错误的唯一识别方式。
