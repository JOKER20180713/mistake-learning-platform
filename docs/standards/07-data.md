# 数据规范

维护人：司浩鸣。逻辑实体与字段含义统一在 [数据字典](../contracts/data.md) 维护，本轮不创建数据库。

| 编号 | 要求 | 检查方法 |
| --- | --- | --- |
| DATA-01 | 表/字段使用小写 snake_case；业务时间 UTC 存储，按用户时区展示；外部 ID 作为不透明字符串 | 对数据字典和响应样例核验，不能由可猜 ID 取代权限检查 |
| DATA-02 | 机构资源必须可直接追溯 organization_id，关系两端归属一致；实体、版本、小问有独立标识 | 构造跨机构外键/关联请求必须拒绝并无部分写入 |
| DATA-03 | 创建/更新时间、行为人和版本完整；修订与审计追加记录，禁止覆盖作答原文掩盖历史 | 反馈更正后能查询旧修订、理由和当前有效修订 |
| DATA-04 | 题目正误属于作答，不能在 question 上设置某学生的全局“错误”标记 | 同题两名学生、一人错一人对，两者统计各自正确 |
| DATA-05 | 结构变更用只增不改的迁移文件，验证升级、重复执行策略与回退/前向修复 | 在干净库和旧结构样本库执行；重复步骤不破坏数据 |
| DATA-06 | 个人信息、敏感正文、内部标识、公开题目分别分级，字段收集有业务目的 | 机构导出与日志不含多余个人字段；样本库无真实学生信息 |
| DATA-07 | 文件、业务行、向量、缓存和导出均登记版本与副本，写入/删除有补偿任务 | 任一阶段中断能重试，已失效内容不能仍被检索 |
| DATA-08 | 共享题库需要来源、授权范围和审核记录，个人上传不自动进入共享索引 | 未授权个人题无法被其他学生推荐命中 |
| DATA-09 | 统计可从有效作答重建，修订不重复计次；未知、待批改、未作答排除分母 | 固定混合状态样本计算得出指定结果，重建与增量一致 |
| DATA-10 | 数据删除列明全部副本与备份处理，恢复时重放删除记录 | 删除演练后查业务、对象、向量、缓存，备份恢复不复活已删正文 |

## 留存与删除基线

以下为试点前需确认的拟定参数，D-04 未关闭前不得收集真实学生生产数据。可用合成数据验证删除流程。

| 数据 | 拟定留存/删除规则 |
| --- | --- |
| 未确认上传 | 30 天后提醒并按明确规则清理；与正式题目无关的孤立文件 24 小时内清理 |
| 正式作答、题目与分析 | 有效服务期间保存；服务终止后的导出窗口拟定 30 天，具体条款在试点前确定 |
| 用户明确删除 | 立即撤销普通访问，在线正文与派生副本目标 24 小时内清除；失败进入补偿队列 |
| 运行日志 | 30 天，只含脱敏运行字段 |
| 最小审计记录 | 180 天，不保存已删除的作答正文；必要期限与适用条款另行确认 |
| 备份 | 最长 30 天滚动到期；受限访问，恢复后先应用删除清单再开放服务 |

删除不是只设置 `deleted_at`。可以短期保留任务状态和脱敏删除凭据，但内容不可继续被下载、推荐或统计回源。不可因备份尚未到期就重新开放在线正文。

## 跨存储处理顺序

上传先写受控临时对象，确认后事务记录文件引用和事件；事件推动分析/向量等派生处理，孤立临时对象由清理任务回收。更新内容产生新版本，检索仅使用当前可用版本。

删除先在业务层阻断访问并写删除事件，再清除缓存、向量、文件和派生导出，逐项记录完成状态。重试按资源及版本幂等；备份恢复必须应用独立保存的删除清单。若一张共享题目仍被其他有效练习引用，只删除学生个人作答和私有派生内容，不误删有合法保留依据的共享题目版本。
