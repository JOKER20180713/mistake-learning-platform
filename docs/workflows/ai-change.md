# 一次模型或提示词变更

适用：识别、知识点匹配、错因分析、嵌入模型、召回阈值或推荐排序变化。当前尚未连接模型，以下为后续执行流程。

1. 确认问题和基准样本，列出本次只改变的变量；检查数据授权和真实调用预算。
2. 保留旧模型配置、提示词、样本及评分规则版本。记录候选方案与成本/延迟影响。
3. 使用固定输入分别获得旧/新结果；离线格式与边界检查先跑，真实模型评测单独执行。
4. 按 AI 规范逐项评分。拒绝/不确定场景和越权、虚构依据等否决项不能被平均分掩盖。
5. 由非作者复核错因与推荐适配样例，登记分歧与处理；模型自评分不能替代人工结论。
6. 嵌入模型变化时重建新版本索引，校验机构范围和题目版本；切换读索引前保留旧版本可回退。
7. 写对比结论、实际费用与失败样例，经评审后发布；运行日志记录版本且不记录学生原文。
8. 上线后观察任务失败、纠错和费用，异常按已登记版本回退。回退模型时检查是否也需回退相应向量索引。

未获得真实模型访问授权或预算时，继续完成规约、替身测试设计和样本标注；不擅自使用个人密钥、真实学生材料或付费额度。
