# 产品定位与范围

## 已确认方向

客户为培训机构，教师组织学生练习。核心价值是把错题材料、具体作答证据、针对性训练和练习反馈连接起来。学生是学习活动主体，教师负责组织与复核，机构管理员负责组织和成员管理。

保留以下完整流程：上传错题与作答、识别确认、知识点关联、错因分析、个人错题积累、题库检索、练习下载与作答、结果反馈、知识点学习记录更新。题目和作答分开，正确与错误作答都纳入记录。

## 首期范围约定

| 包含 | 边界 |
| --- | --- |
| 机构、班级与成员 | 邀请加入、明确教师与班级授权；账号可有多个机构成员身份，数据按当前机构隔离 |
| 学生材料上传 | 单题 JPG/PNG，题干与作答可分图；文件限制见产品规范 |
| 识别与确认 | 原图对照、编辑疑点、确认后再分析；仅题干可分析考点，但具体错因待补作答 |
| 分析与错题 | 具体步骤证据、可修正的知识点关联、历史分析与订正记录 |
| 教师组织练习 | 教师从可用题目组卷，选择授权班级或学生，发布固定题目版本，学生下载与反馈 |
| 正误反馈 | 客观题核验答案判分；主观题自评或教师评阅，来源分开展示 |
| 学习记录 | 按知识点查看练习、错误、订正和待复习项；不以单次答对宣称稳定掌握 |
| 机构题库维护 | 可追溯来源，审核后发布；个人材料不自动共享 |

首期学科、学段与教材见待决项 D-01。在确定覆盖范围前，不对外承诺全学科识别或题库覆盖。

本轮规范阶段不包含应用实现。后续首发也暂不包含自动生成新题补库、整卷复杂切题、复杂证明题无人复核判分、付费支付、家长端和跨机构内容交易。它们可在独立变更中提出。

## 角色主路径

- 学生：加入机构 → 接收教师练习或上传错题 → 确认识别 → 查看分析 → 完成练习 → 逐题反馈 → 查看订正与后续任务。
- 教师：选择授权班级 → 查看学生材料及待复核项 → 选择推荐题并组卷 → 发布 → 查看完成情况 → 复核争议结果 → 安排复习。
- 机构管理员：维护机构、班级、成员及教师授权 → 查看组织层面的运营统计 → 调整配额；默认不据管理角色直接读取学生作答正文。

## 拟定页面清单

以下为设计基线，页面尚未实现；页面路径与 API 路径分开维护。

| 页面 | 路径 | 角色与主操作 |
| --- | --- | --- |
| 登录与机构选择 | `/login`、`/organizations` | 所有成员，建立身份与当前机构上下文 |
| 机构成员与班级 | `/organization/members`、`/organization/classes` | 机构管理员，维护成员和授权 |
| 教师工作台 | `/teacher` | 教师，待复核与近期练习 |
| 班级学习记录 | `/teacher/classes/:classId` | 授权教师，学生列表及学习摘要 |
| 教师练习管理 | `/teacher/practice-sets`、`/teacher/practice-sets/:id` | 教师，草稿、发布与反馈查看 |
| 机构题库 | `/teacher/questions` | 授权教师，检索与提交题目审核 |
| 学生首页 | `/student` | 学生，待完成练习与待复习项 |
| 上传与识别确认 | `/student/uploads`、`/student/uploads/:id` | 学生，上传、确认、重试 |
| 个人错题 | `/student/mistakes`、`/student/mistakes/:id` | 学生，分析、作答与订正历史 |
| 我的练习与反馈 | `/student/practice-sets`、`/student/practice-sets/:id` | 学生，下载、填写逐题结果和提交 |
| 知识点记录 | `/student/knowledge` | 学生，查看正误作答与证据数量 |

无效页面显示 404；会话过期引导重新登录并保留可安全恢复的草稿。页面跳转不代替服务端资源校验。

## 完整流程的产品验收

使用两家虚构机构、各两名教师和两名学生验证隔离。完成一次教师组卷、学生下载、提交正确/错误/部分正确/未作答结果、教师更正及统计更新；同时验证未被分配的学生无法查看练习附件。

首次试点衡量实际完成闭环的学生数、结果反馈率、人工纠错比例和每次有效分析成本。此处是观察方向，不声明已测得留存、提分或识别准确率，也不设置收费与商业目标。具体计算口径在埋点变更中确定。
