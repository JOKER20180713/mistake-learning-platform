# 项目术语表

| 规范名称 | 数据概念 | 含义与禁止混淆 |
| --- | --- | --- |
| 机构 | organization | 数据隔离和成员管理边界，不与学校或班级混用 |
| 班级 | class | 机构内教学分组；教师授权和学生成员关系各自维护 |
| 题目 | question | 可版本化的题干、选项、图形与参考解答，不携带某学生的正误属性 |
| 小问 | question item | 可独立作答、判定和关联知识点的题项 |
| 上传材料 | upload | 原始题图或作答图；不自动等于有效题目或共享题库内容 |
| 作答记录 | attempt | 某学生对某题项某一轮的答案、结果与判定来源 |
| 错题 | mistake | 学生在特定题目上需要订正或复习的个人记录，关联历史错误作答 |
| 知识点 | knowledge point | 目录内稳定编号的知识项；名称相似不代表同一编号 |
| 错因分析 | analysis | 针对具体作答证据的分析，不等于题目通用解析 |
| 参考解析 | explanation | 题目解法与依据，来源和核验状态必须可见 |
| 相似练习 | recommendation | 从可用题库检索出的训练候选，不表示自动生成的新题 |
| 练习单 | practice set | 固定题项顺序及版本快照的练习集合，不与单次作答轮次混用 |
| 分配记录 | assignment | 练习单与接收学生的关联，决定学生访问资格 |
| 反馈 | submission | 学生提交一轮逐题结果的行为；不是任意修改统计数字 |
| 订正 | correction | 对已有作答问题进行修改或补充，保留历史 |
| 已巩固 | consolidated | 基于后续练习证据的复习状态，不等于“曾答对一次” |
| 未作答 | unanswered | 学生明确声明没有作答；区别于系统尚未收到结果的“未知” |
| 待批改 | pending review | 已有作答，尚无确定判定；不算正确或错误 |

界面、API 说明、数据字典与规约沿用本表。字段命名使用英文并在数据字典解释，用户界面使用规范中文名。新增近义词前先修改术语表，避免“练习卷/试卷/练习本”在同一业务内无定义混用。
